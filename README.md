# DS-Airsoft-Grenade
## Current Release: [V4.5](/V4.5)
This project is a reusable, timed or impact-activated airsoft simulation grenade designed to operate with .209 primers, 8-shot ring caps, or adult/thunder/super snaps. The device is engineered with a strong emphasis on reliability, repeatability, and user safety. It is a zero-fragmentation system intended solely to produce an audible report, with no shrapnel or expelled components during operation. All exhaust gases and particulate byproducts are redirected and dispersed internally before exiting the device, significantly reducing localized pressure and minimizing external explosive forces.  
The design prioritizes consistent performance across a wide range of 3D printers and environmental conditions. Each component is optimized for printability, structural strength, and impact resistance while maintaining a compact form factor and minimal overall mass. A modular architecture allows both timed and impact fuse mechanisms to be easily interchanged between grenade bodies and compatible ammunition types, enabling flexibility in configuration, maintenance, and future expansion. This modularity, combined with durable construction, ensures the system remains adaptable, cost-effective, and dependable for repeated use in simulation environments.
