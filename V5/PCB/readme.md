# How to Order PCB  

1. Navigate to [JLCPCB](jlcpcb.com). Create an account and navigate to the Standard PCB/PCBA order menu.
2. Upload the [PCBV2.0.0.zip](PCBV2.0.0.zip). It is the gerber file.
3. Select your board quantity. Change PCB thickness to 1.0mm. Change the PCB color if you want. Select PCB Assembly. Leave all other specifications as they are.
4. Click Next and verrify the board is displayed. Click Next again.
5. Upload the [BOM](bom.csv) File. Upload the [CPL](positions.csv) File (positions). Then Click process BOM & CPL.
6. All parts should prepopulate. Ignore the error for an unmatched component J4 Motor. Click Next and select do not place for the motor component error.
7. Components are already properly placed so just click next.
8. Select a product description. I typically do Sensor\Controller\Precision Intrument, Battery - HS Code 853890. Then save to cart.
9. At this point you can procede to checkout
10. Don't forget to order the switch and connectors for the board listed in the BOM. These parts will need to be hand soldered.
